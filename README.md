# 진심 CS 체험 앱 — 무료 설치 주소 만들기

기존 GitHub 계정과 파일 탐색기만 사용합니다. Pro 업그레이드나 다른 호스팅 계정은 필요 없습니다.

1. 이 배포본 ZIP을 받고 압축을 풉니다.
2. GitHub에서 테스트 전용 Public 저장소를 새로 만듭니다. 기존 운영 저장소는 비공개로 유지합니다.
3. index.html, manifest.webmanifest, sw.js, assets, icons 및 나머지 배포 파일을 새 저장소 첫 화면에 올립니다. 바깥 폴더가 아닌 그 안의 내용을 업로드합니다.
4. 새 공개 저장소의 Settings → Pages에서 Source: Deploy from a branch, Branch: main, 폴더: /(root)를 선택하고 Save를 누릅니다.
5. 배포 완료 후 Visit site에 표시되는 HTTPS 주소를 휴대폰에서 엽니다.

갤럭시: Chrome → 앱 설치. 아이폰: Safari → 공유 → 홈 화면에 추가. PC에서는 앱 설치 버튼을 눌러 QR을 보여줄 수 있습니다.

이 파일들은 실제 접수·사진·Google/Slack 연결값이 없는 독립 체험 앱입니다. 연습 기록은 각 기기에만 저장됩니다. 실제 운영 프로젝트 파일을 공개로 올리지 않습니다.
